# Módulo A — Diagnóstico Inicial

Ponto de entrada obrigatório. Sem diagnóstico rigoroso, qualquer análise posterior opera sobre
premissas não-validadas. Aplique **dois frameworks complementares em paralelo** — Lean Canvas
e BMG — para explicitar todos os componentes do modelo e revelar inconsistências estruturais.

## Lean Canvas (9 blocos)

Adaptado por Ash Maurya do Business Model Canvas de Osterwalder. Ênfase em **problema-solução**
(vs produto-mercado), ideal para startups em validação.

| Bloco | Função | Pergunta-chave |
|-------|--------|----------------|
| 1. Problema | Top 3 problemas do segmento-alvo | Que dor real você resolve? |
| 2. Segmento de Clientes | Persona-alvo + early adopters | Quem paga e quem usa? |
| 3. Proposta de Valor Única | Mensagem clara de diferenciação | Por que comprar de você e não do incumbente? |
| 4. Solução | Top 3 features que endereçam o problema | Como você resolve, em uma frase por feature? |
| 5. Canais | Caminho até o cliente (paid, owned, earned) | Como o cliente descobre e compra? |
| 6. Fontes de Receita | Modelo de monetização | Quem paga, quanto, com que frequência? |
| 7. Estrutura de Custo | Custo fixo + variável + CAC | Quanto custa operar e crescer? |
| 8. Métricas-Chave | Top 3 KPIs de validação | Que número mostra se está funcionando? |
| 9. Vantagem Injusta | Defensabilidade real (não feature) | O que é difícil de copiar? |

## BMG (Business Model Generation)

Expande o Lean Canvas com profundidade em quatro blocos, útil para negócios em **scaling**:
- **Parcerias-Chave** — quem habilita o modelo.
- **Atividades-Chave** — o que precisa ser executado.
- **Recursos-Chave** — o que precisa ser possuído.
- **Relacionamento com Clientes** — como o cliente é adquirido, retido e expandido.

Regra prática: ideação → Lean Canvas costuma bastar; com tração → aplique os dois combinados
para revelar gaps que cada um isoladamente não captura.

## SWOT exploratório (preliminar)

No diagnóstico o SWOT é **qualitativo e exploratório** (identifica onde investigar mais fundo);
no Módulo B ele é **quantitativo e conversível em scores**.

| Quadrante | Conteúdo | Estratégia derivada |
|-----------|----------|---------------------|
| Forças (Strengths) | Vantagens internas identificáveis e controláveis | Alavancar (SO): usar forças para capturar oportunidades |
| Fraquezas (Weaknesses) | Limitações internas que reduzem competitividade | Corrigir (WO): mitigar fraquezas para capturar oportunidades |
| Oportunidades (Opportunities) | Fatores externos favoráveis exploráveis | Perseguir (SO): alinhar forças com oportunidades |
| Ameaças (Threats) | Fatores externos adversos potenciais | Defender (ST): usar forças para neutralizar ameaças |

## Output do módulo

Três artefatos:
1. **Perfil estruturado** de uma página: estágio, segmento, modelo, tração, time, capital.
2. **Lean Canvas** preenchido (9 blocos).
3. **BMG** complementar (4 blocos adicionais).

Sinalize **explicitamente inconsistências** entre os dois canvas (ex.: segmento definido no
Lean não corresponde ao relacionamento descrito no BMG) e force a resolução antes de avançar
para Viabilidade. Entregue também **5 pontos fortes / 5 pontos fracos**.

> Diagnóstico rigoroso é pré-requisito de viabilidade útil. Sem canvas preenchido, scores de
> viabilidade são números sem contexto.
