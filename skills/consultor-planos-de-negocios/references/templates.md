# Templates Operacionais

Instrumentos prontos para preencher. O texto entre colchetes `[ ]` é placeholder; o exemplo em
itálico indica o nível de granularidade esperado.

## Template — Lean Canvas (exemplo preenchido)

```
LEAN CANVAS — TEMPLATE PREENCHIDO

1. PROBLEMA
   • Falta de visibilidade de estoque em tempo real
   • Perdas por validade não rastreadas
   • Tempo excessivo em contagem manual

2. SEGMENTO DE CLIENTES
   • Microvarejistas (1-5 lojas) de alimentos perecíveis
   • Early adopters: mercearias de bairro em SP capital

3. PROPOSTA DE VALOR ÚNICA
   • "Veja seu estoque em tempo real de qualquer lugar,
     sem planilhas. Reduza perdas em até 30%."

4. SOLUÇÃO
   • App mobile com scan de código de barras
   • Dashboard web com alertas de validade
   • Integração com fornecedores para reposição automática

5. CANAIS
   • Indicação de fornecedores (B2B2B)
   • Google Ads segmentado por segmento
   • Trilha de conteúdo para microvarejistas

6. FONTES DE RECEITA
   • R$149/mês por loja (SaaS subscription)
   • R$49/mês por usuário adicional
   • Marketplace fee (5% sobre reposições via plataforma)

7. ESTRUTURA DE CUSTO
   • Custo cloud: R$8/usuário/mês
   • CAC: R$420 (paid + content)
   • Custo de serving: R$12/cliente/mês
   • Burn fixo: R$180k/mês (time de 9)

8. MÉTRICAS-CHAVE
   • MRR e crescimento MoM
   • Retenção D90
   • NPS
   • Margem bruta

9. VANTAGEM INJUSTA
   • Integração nativa com 12 principais distribuidores
   • Dataset de consumo por região (3 anos de histórico)
```

## Template — Term Sheet Checklist (15 itens)

| Item | Status | Observação |
|------|--------|------------|
| Valuation (pre-money) | [ ] | Confirma range razoável vs comparáveis |
| Quantia investida | [ ] | Confere com plano de uso |
| Diluição implícita | [ ] | Calcular % exato pós-round |
| Liquidation preference | [ ] | 1x non-participating é padrão |
| Anti-dilution | [ ] | Broad-based weighted average aceitável |
| Pro-rata rights | [ ] | Confere prazo e elegibilidade |
| Board composition | [ ] | Equilíbrio founders × investidores × independentes |
| Vesting de founders | [ ] | 4 anos / 1 ano cliff padrão |
| Drag-along | [ ] | Threshold ≥ 60% aceitável |
| Tag-along | [ ] | Sem restrições excessivas |
| Information rights | [ ] | Relatórios mensais + auditoria anual |
| Exclusividade / No-shop | [ ] | 30-60 dias é padrão; mais que isso recusar |
| Conditions precedent | [ ] | Lista clara e alcançável |
| Expenses / Fees | [ ] | Caps razoáveis para fees de advogados |
| Governing law | [ ] | Brasil preferencial para operações BR |

## Template — Stress Test Scenarios

```
STRESS TEST SCENARIOS — TEMPLATE

CENÁRIO OTIMISTA (Base case, P50)
  • Receita: R$ [X] em 12 meses
  • CAC: R$ [Y], LTV/CAC: [Z]
  • Burn: R$ [W]/mês
  • Runway sem nova captação: [N] meses
  • Valuation implícito: R$ [V]

CENÁRIO PESSIMISTA (P25 — 25% de probabilidade)
  • Receita cai 50% em 6 meses → R$ [X * 0.5]
  • CAC sobe 30% → R$ [Y * 1.3]
  • Churn sobe 50% → [% atual * 1.5]
  • Burn ajustado: R$ [W * 1.36]/mês
  • Runway: [N * 0.73] meses
  • Ação: cortar marketing 50%, freeze hiring

CENÁRIO SEVERO (P10 — 10% de probabilidade)
  • Receita cai 75% em 3 meses → R$ [X * 0.25]
  • CAC sobe 60%, Churn dobra
  • Burn com cortes: R$ [W * 0.85]/mês
  • Runway: [N * 0.40] meses
  • Ação: RIF 25%, pivot para segmento maior ticket

CENÁRIO BLACK SWAN (P1 — 1% de probabilidade)
  • Evento: [perda de cliente-chave / regulação / shutdown]
  • Receita: R$ [X * 0.10]
  • Ação: descontinuar ou pivot radical
  • Asset residual: [marca / dados / time]
```
