# Glossário Técnico (50+ termos)

Definições concisas e operacionais dos termos empregados nas interações com o agente.

| Termo | Definição |
|-------|-----------|
| AARRR | Framework de métricas de growth (Acquisition, Activation, Retention, Revenue, Referral). Criado por Dave McClure, mapeia o funil completo de crescimento do cliente. |
| Anti-dilution | Cláusula de term sheet que protege investidores em down rounds. Broad-based weighted average é padrão; full ratchet é punitivo aos founders. |
| ARR (Annual Recurring Revenue) | Receita recorrente anualizada. MRR × 12. Métrica central para SaaS e subscription. |
| Burn Rate | Taxa mensal de consumo de caixa. Burn líquido = despesas − receitas. Determina o runway. |
| CAC (Customer Acquisition Cost) | Custo total para adquirir um cliente. Inclui marketing, vendas e ferramentas. Calculado por canal e consolidado. |
| Cap Table | Tabela de capitalização mostrando % de cada sócio (founders, investidores, option pool) e direitos preferenciais. |
| Churn | Taxa de perda de clientes (mensal ou anual). Voluntário (cancelamento) vs involuntário (falha de pagamento). |
| Cohort | Grupo de clientes adquiridos no mesmo período. Análise por coorte revela padrões de retenção e LTV. |
| CSAT (Customer Satisfaction) | Métrica de satisfação pós-interação, tipicamente em escala 1-5. |
| DCF (Discounted Cash Flow) | Valuation baseado em projeção de fluxos de caixa futuros descontados a valor presente via WACC. |
| Dilution | Redução da % de um sócio em rodada de capital. Diluição = (1 − % pré-round / % pós-round). |
| Drag-along | Direito que obriga minoritários a vender nas mesmas condições em exit aprovado pela maioria. |
| eNPS (Employee NPS) | NPS aplicado a funcionários. Mede probabilidade de recomendar a empresa como empregadora. |
| EV (Enterprise Value) | Valor de empresa = Market Cap + Dívida − Caixa. Base para múltiplos como EV/Receita, EV/EBITDA. |
| GMV (Gross Merchandise Value) | Volume bruto transacionado em marketplace. Não confundir com receita (a comissão sobre o GMV). |
| Gross Margin | Margem bruta = (Receita − Custo Direto) / Receita. SaaS saudável: > 70%; serviços: 30-50%. |
| IRR (Internal Rate of Return) | Taxa interna de retorno. Métrica de rentabilidade para investidores de VC e PE. |
| LTV (Lifetime Value) | Receita líquida total esperada de um cliente durante seu tempo de vida ativo. LTV/CAC ≥ 3 é saudável. |
| Lean Canvas | Framework de 9 blocos adaptado por Ash Maurya do Business Model Canvas. Foco em problema-solução, ideal para startups. |
| Liquidation Preference | Direito do investidor de receber valor antes dos founders em exit. 1x non-participating é padrão. |
| LP (Limited Partner) | Investidor que aporta capital a um fundo de VC ou PE. Não participa de decisões de investimento. |
| MRR (Monthly Recurring Revenue) | Receita recorrente mensal. Métrica central de SaaS subscription. Exclui receita one-off. |
| North Star Metric | Métrica única que melhor captura o valor entregue ao cliente. Guia priorização de produto e growth. |
| NPS (Net Promoter Score) | Métrica de lealdade: % promotores − % detratores. Escala −100 a +100. Acima de 50 é excelente. |
| OKR (Objectives & Key Results) | Framework de meta-setting. Objectives qualitativos e ambiciosos; Key Results quantificáveis. |
| Payback Period | Tempo para recuperar o CAC. < 12 meses é saudável em SaaS B2B; > 24 meses é preocupante. |
| PMF (Product-Market Fit) | Momento em que o produto atende demanda de mercado de forma sustentável. Sinal: retenção D30 > 40% e growth orgânico. |
| Pro-rata Rights | Direito do investidor de manter % em rodadas futuras investindo proporcionalmente. |
| Runway | Meses de operação sem nova captação. Runway = Caixa / Burn mensal. Mínimo saudável: 12 meses. |
| SaaS (Software as a Service) | Software entregue via assinatura, sem instalação local. Métricas-chave: MRR, churn, NRR. |
| Scorecard Method | Valuation para early-stage comparando com startups similares e ajustando por time, mercado, tração. |
| Series A/B/C | Rodadas consecutivas. A: PMF; B: escala; C+: growth/pre-IPO. Tickets e diluições crescem. |
| SWOT | Análise de Forças, Fraquezas, Oportunidades e Ameaças. Estratégias SO/WO/ST/WT derivadas. |
| TAM (Total Addressable Market) | Mercado total endereçável se 100% fosse capturado. Top-down ou bottom-up. |
| Term Sheet | Documento que formaliza condições de investimento. Não é contrato definitivo, mas guia os documentos finais. |
| Vesting | Cronograma de aquisição de equity por founders/employees. Padrão: 4 anos com 1 ano cliff. |
| VC Method | Valuation estimando exit em 5-7 anos, descontando por IRR-alvo (30-50%) e aplicando diluição futura. |
| WACC (Weighted Average Cost of Capital) | Custo médio ponderado de capital. Taxa usada para descontar fluxos de caixa no DCF. |
| Network Effect | Fenômeno onde cada novo usuário aumenta o valor para os existentes. Plataformas, marketplaces, redes. |
| Viral Coefficient (K) | Número médio de novos usuários trazidos por cada usuário existente. K > 1 = crescimento viral. |
| Customer Success (CS) | Função focada em maximizar valor entregue ao cliente pós-venda. Reduz churn e gera expansão. |
| Data Room | Repositório virtual de documentos confidenciais para due diligence. Organizado por categoria. |
| Down Round | Rodada com valuation inferior à anterior. Aciona anti-dilution e prejudica moral. |
| ESOP (Employee Stock Ownership Plan) | Pool de opções de ações para funcionários. Típico: 10-20% do capital. Vesting 4 anos / 1 cliff. |
| Exit | Evento de liquidez para investidores e founders: IPO, M&A ou secondary sale. Horizonte VC: 5-7 anos. |
| M&A (Mergers and Acquisitions) | Fusões e aquisições. Exit via M&A é mais comum que IPO em volume de transações. |
| NRR (Net Revenue Retention) | Receita retida líquida = (Receita inicial + expansão − churn − contração) / Receita inicial. NRR > 100% é excelente. |
| PESTEL | Análise de ambiente externo: Político, Econômico, Social, Tecnológico, Ambiental, Legal. Complementa SWOT. |
| Porter 5 Forças | Framework de análise competitiva: rivalidade, entrantes, substitutos, fornecedores, compradores. |
| Single vs Double Trigger | Tipos de vesting acceleration. Single: aquisição sozinha acelera. Double: aquisição + demissão em até 12m. |
| Tag-along | Direito de minoritários de vender nas mesmas condições dos majoritários. Protege em exits. |
| Unit Economics | Análise de rentabilidade por unidade (cliente ou transação). CAC, LTV, payback, margem de contribuição. |
